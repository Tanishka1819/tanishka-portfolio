Featured project

RAG Document Assistant

Ask questions about PDFs and get answers that name the page they came from. If the documents do not contain the answer, it says so instead of guessing.

  1. Each PDF page is split into overlapping chunks of text.
  2. A sentence-transformers model turns every chunk into an embedding.
  3. The question is embedded too, and the 4 closest chunks are found with cosine similarity.
  4. Gemini answers using only those chunks and cites the source file and page.

Retries handle temporary 503 errors from the model API. Deployed on Streamlit Community Cloud.
